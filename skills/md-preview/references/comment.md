# コメント機能ユーザーガイド

プレビュー中の Markdown に「ここが気になる」というコメントをその場で付け、まとめて
コピーして Claude Code などに貼るための機能。difit の「差分にコメント→AI に渡す」体験を
レンダリング済み Markdown に移植したもの。マウスでもキーボードだけでも操作できる。

## 基本の流れ

1. `c` でコメントモードに入る（右サイドバーがコメントタブで開き、見えているユニットに
   カーソル枠が乗る）
2. コメントしたいユニットを選ぶ（クリック、またはキーボードで移動）
3. コメントを入力して保存する
4. サイドバーの「全部コピー」（またはキーボードの `y`）でまとめてコピー
5. Claude Code に貼る（`- file:line` ＋引用＋コメントの形式なので、AI がファイルを開いて
   位置を当てやすい）

コメントできるユニットは、見出し・段落・リスト項目・表（表全体で 1 ユニット）・引用・
コードブロック（ブロック全体）・`<details>` の折りたたみ・フロントマター（ブロック全体）。
raw 表示（⌘R）と非 md ファイルのソースビューでは **1 行が 1 ユニット**になる。

## マウス操作

- モード中、ユニットにホバーすると左に `+` ハンドルが出る。クリックでそのユニットを対象に
  コメント入力ポップオーバーが開く。
- ホバーするとカーソル枠もそこへ移る（`+` と枠が常に同じユニットを指す）。逆にキーを
  押すと `+` は畳まれる。マウスとキーボードを持ち替えても「今どこを指しているか」は
  常に 1 つだけ出る。ただし `Shift+j`/`k` でレンジを掴んでいる間はホバーで動かない。
- **ドラッグで複数ユニットをまとめて 1 コメント**にできる（レンジ選択）。
- 保存すると対象の左に色帯と 💬 バッジが付く。💬 バッジのクリックで編集。
- コメント済みユニットにホバーすると内容がプレビュー表示される（モード外用。モード中は
  埋め込み表示がその場で読める）。
- サイドバー一覧の各コメントをクリックすると、その `file:line` へジャンプする。

## キーボード操作（マウス不要）

モードに入ると本文にカーソル枠が乗り、以下ですべて完結する。

| キー | 動作 |
| --- | --- |
| `c` | コメントモードの開始 / 終了 |
| `j` / `k`（`↑` / `↓`） | ユニット・カーソルを移動 |
| `Shift+j` / `Shift+k` | 複数ユニットのレンジを伸縮 |
| `Enter` | カーソル位置（またはレンジ）にコメントを付ける |
| `⌘+Enter` | 入力を保存 |
| `Esc` | 入力を取消 → もう一度でモード終了 |
| `n` / `p` | 付けたコメントを file→行順に巡回してジャンプ（別ファイルも自動で開く） |
| `e` | 対象コメントを編集 |
| `x`（または `Delete`） | 対象コメントを削除 |
| `y` | 全部コピー |

レンジを伸ばしている間は、範囲全体が塗られ、両端に別の枠が付く（実線＝いま動かしている
側、破線＝掴んだ起点）。どこからどこまでを掴んでいるかが読める。

配色はテーマの「選択中」の色（ファイルツリーで開いているファイルに付く色）と揃う。

`e` / `x` の対象は、`n` / `p` で巡回中ならそのコメント、そうでなければカーソル位置の
コメント（カーソルはホバーでも動くので、ホバー先のコメントが対象になる）。操作の結果は右下に短いトーストで表示される（「2 / 5 file:line」「全部コピー
しました」「コメントを削除しました」など）。

`d` / `u`（半ページ）・`Space`（1 ページ）・`g` / `G`（冒頭 / 末尾）のスクロールはモード中
も効く。

## raw / ソース表示のコメント

`⌘R` の raw 表示と、非 md ファイル（`.rs` / `.txt` など）のソースビューでは、1 行が
1 ユニットになる。クリックで 1 行、ドラッグで複数行、`j`/`k` と `Shift+j`/`k` も同じ。
引用にはソースの行がそのまま入る。

- プレビューと raw の行番号はどちらも**ソースの行**なので、同じファイルなら両方の
  コメントが同じ `file:line` の並びに混ざる。raw で段落の途中の行に付けたコメントは、
  プレビューへ戻すとその行を含む段落に印が付く。
- 素の閲覧中はコードをふつうに選択・コピーできる（行の当たり判定はモード中だけ効く）。
  モード外でも 💬 バッジは押せる／ホバーでプレビューできる。
- コメントは**どの表示で付けたか**を覚えている。一覧では raw 由来に `raw` の印が付き、
  `n` / `p` の巡回・一覧クリック・`e` の編集は、その表示へ切り替えてから着地する
  （raw のコメントへ飛べば raw 表示になり、プレビューのコメントへ戻れば raw は畳まれる）。
  非 md ファイルは raw トグル自体が無いので印も切り替えも無い。

## 本文への埋め込み表示（モード中）

コメントモード中は、各コメントが**アンカーの直下に GitHub 風に埋め込み表示**される。
本文を読み下ろすだけで指摘とその対象が並んで見え、その場で編集 / 削除もできる。

- レンジコメントは範囲の**最後のユニットの直後**に出る（ヘッダの `file:line` が範囲を示す）。
- 同じユニットに付いた複数のコメントは 1 つの枠にまとまって並ぶ。
- 埋め込みの本文は選択・コピーできる（ドラッグのユニット選択は始まらない）。
- モードを抜けると埋め込みは消え、💬 バッジとホバープレビューだけが残る。
- raw / ソース表示では出ない（1 行 1 ユニットの積み上げで位置を合わせているため、
  間にブロックを挟めない）。raw のコメントはサイドバー一覧で読む。
- モード出入りで本文の高さが変わるぶんはスクロール位置が自動補正され、見ていた場所は
  動かない。

## 一覧（サイドバーの Comment 表示）

コメントモードに入ると、右サイドバー（アウトラインと同じ場所）がまるごと Comment に
置き換わり、全ファイルのコメントが `file:line` → 行順で並ぶ。各コメントは編集 / 削除
でき、「全部コピー」でまとめてコピー、「全消去」で全削除。サイドバーなので一覧が本文に
被らない（本文はガター分だけ左へ避ける）。

**サイドバーが Comment 表示＝コメントモード中**で、モード外のサイドバーは Outline だけ
（モードの入口は `c` / 💬 ピル / バッジ / 右クリックメニュー）。`c` / `Esc`、サイドバーの
×、⌘T（Outline へ切替）で抜けられ、サイドバーはモードに入る前の状態（Outline / 閉じる）
に戻る。コメントを付けた 💬 マークはモード外でも本文に残る。コメントが 1 件以上ある状態で
モードを抜けると、右下に「💬 N」のピルが出て、クリックで一覧に戻れる。

一覧のハイライトは 2 段階:

- **薄い色**: アンカーが画面内にあるコメント（スクロールに追従、複数同時にあり得る）
- **濃い色＋左バー**: `n` / `p` の巡回対象（1 件。巡回すると一覧側も追従スクロールする）

## フォルダモードでの複数ファイル

フォルダを開いている（サイドバーがある）ときは、`]` / `[` で表示中のファイルを次 / 前へ
巡回、`Tab` で本文とファイルツリーのフォーカスを切り替えられる。別ファイルに移ってもコメントは
一覧に蓄積され続けるので、複数ファイルを横断してレビューしてからまとめてコピーできる。

## コピーされる形式

```text
- docs/plan.md:15
> 認証は JWT を使う。アクセストークンは短命にして…

リフレッシュトークンの扱いは？

- docs/plan.md:18-20
> POST /auth/token
> { "grant_type": "password", ... }

このリクエスト、レート制限は？
```

- ファイル行は `- ` 始まり。単一行は `:line`、レンジは `:start-end`。行番号が取れない
  ユニットは `- ファイル名` だけになる。
- 引用は `>` ブロックで、直後に空行を 1 行はさむ。続くコメント本文は引用の外に置かれる。
  ソースの空行は `>` だけの行として残る（行数と引用がずれないように）。
- 複数コメントは file → 行番号の順に並ぶ。

## 制限・注意

- コメントはセッション内のメモリのみで、ファイルには保存されない（コピーして使う前提）。
- 削除は確認なしで即時（取り消し不可）。
- 付けられないのは git 差分（⌘D）と `.html` の iframe 表示。
- raw / ソース表示で行コメントが使えるのは 10,000 行までのファイル（それを超えると
  シンタックスハイライトごと無効になる大きさなので、行の単位も作らない）。モードに
  入るとトーストで知らせる。
