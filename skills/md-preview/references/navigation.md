# ナビゲーションと表示機能

`md` はキーボードだけで読み歩けるように作られている。ここでは移動系のキー操作と、
検索・アウトライン・diff・raw といった各機能、`.html` / 非 md ファイルの表示のされ方を
まとめる。`?` キー（または右クリックメニュー）でアプリ内にショートカット一覧のオーバーレイも
出せる。

## キーボードで読み歩く

スクロールは less/vim 流の素キーで、全モード共通:

- `j` / `k` … 1 行下 / 上
- `d` / `u` … 半ページ下 / 上
- `Space` / `Shift+Space` … 1 ページ送り / 戻し
- `g` / `G` … 冒頭 / 末尾へ
- `/` … 検索を開く

フォルダを開いているとき（サイドバーがある）は、さらに:

- `]` / `[` … 表示中のファイルを次 / 前へ巡回
- `Tab` … 本文ペイン ⇄ ファイルツリーのフォーカス切替
- ⌘B … 左サイドバー（ファイルツリー）を開閉。畳むと本文がその分広がる
- ツリーにフォーカス中 … `j` / `k` 移動・`g` / `G` 端・`Enter` または `l` で開く＆フォルダ展開・`h` で畳む / 親へ

⌘B で畳んだ状態でも `Tab` は効き、開いてからツリーへ移る。畳んだ後に残る細い縦線
（リサイザ）はクリックでも開ける。開閉状態はウィンドウを閉じるまで（幅と同じくセッション内のみ）。

スクロール素キー（`j` `k` `d` `u` `Space` `g` `G`）と `?`・`]` / `[`・`Tab`・
⌘F / ⌘R / ⌘D / ⌘T / ⌘P / ⌘B / ⌘W は、`.html` の iframe にフォーカスがあっても効く
（html 表示中でも読み歩き・ファイル移動・検索が死なない）。
素キーの `/` だけは例外で、iframe にフォーカスがあるときは効かない（後述）。

## 検索（⌘F）

ページ内検索バーを開く。`Enter` / `Shift+Enter`（または `↑` `↓`）で前後のヒットへ移動、
`Aa` ボタンで大文字小文字の区別を切替、`Esc` で閉じる。選択テキストがあれば初期クエリに入る。
html 表示中は iframe の中身も対象になる（後述）。

## ファイル検索（⌘P。フォルダモード限定）

ファイル名のあいまい検索でフォルダ内のファイルを開く（部分列マッチ。`paljs` で
`src/palette.js` に当たる）。`↑` `↓`（`Tab` / `⌃n` `⌃p` も可）で移動、`Enter` で開く、`Esc` で閉じる。

**未入力のときは git で変更のあるファイルが先頭に並び、`+N −M` の変更行数が付く**
（行数を数えられないバイナリ等は `●`）。検索中も変更のあるファイルは少し優先される。
つまり **`⌘P` → `Enter` が「いま触っているファイルへ飛ぶ」操作**になる。⌘D の差分表示は
モードとして維持されるので、**⌘D で差分を出したまま ⌘P で飛べば、飛んだ先の差分がそのまま出る**
（差分のあるファイルを次々見ていける）。

一覧はサイドバーのツリーと違い `node_modules` 等を除外して再帰探索する。除外や探索上限の
向こう側にあるファイルでも、変更があれば一覧に載る。探索を打ち切った場合は入力欄の下に
その旨の警告が出る。

## アウトライン（⌘T）

見出しのアウトライン（見出しナビ）を開閉する。ウィンドウが十分広く見出しが 3 つ以上あれば
右サイドバーに自動表示され、狭い画面では自動で退避する。項目クリックでその見出しへスクロールし、
スクロールに追従して現在位置がハイライトされる。

## git 差分表示（⌘D）

`git diff HEAD` を VSCode 風のインラインソース差分で表示する（右下のトグルでも切替可）。
行＋行内の文字単位で強調（追加＝緑 / 削除＝赤）、全ファイル対応、モードとして維持される。
トグルには変更行数の `+N −M` バッジが付く。raw 表示とは排他。
差分のあるファイルへ移動するには ⌘P（上記。未入力で変更ファイルが先頭に並ぶ）を使う。

## raw（ソース）表示（⌘R）

レンダリング前の生ソースを構文ハイライト付きで表示する（右下のトグルでも切替可）。
通常表示がレンダリング結果になる `.md` 系・`.html` 系ファイルで有効で、diff とは排他。
その他のファイルは通常表示が既にソースなので raw トグルは出ない。

## `.html` / `.htm` ファイル

**iframe でそのままレンダリング表示**される（CSS も JavaScript も効く、ミニブラウザ方式）。
⌘R（右下トグル）で生ソース表示に切り替えられる。手元のローカルファイル閲覧用途のため
sandbox は付けていない。

⌘F の検索は iframe の**中身**にも効く。html は自分で作った文書ではないので、中身を
書き換える `<mark>` ではなく CSS Custom Highlight API（`::highlight()`）で塗る。本文の DOM は
変えず、`::highlight()` の色を決めるスタイルシートを 1 枚差すだけなので、ページ自身の
JavaScript とぶつからない（バーを閉じるとそのシートも外す）。アウトライン（TOC）は html の
**中身**には効かない。

素キーの `/` は iframe にフォーカスがあるときは転送しない。rustdoc・MkDocs・Docusaurus など
`/` を自前の検索ショートカットに使う生成 html は多く、転送するとページ側の検索 UI と
このアプリの検索バーが同時に開いてしまうため。iframe 内から検索を開くのは ⌘F を使う。

検索が届かない範囲（いずれも黙って 0 件になる）:

- 外部サイトへ遷移した iframe（cross-origin）
- Web Components の shadow DOM の中
- CSS Custom Highlight API 非対応の WebKit（Safari 17.2 未満）。塗れない環境では
  他人の文書を書き換えないほうを選び、iframe を検索対象から外す
- フォルダモードで iframe 内の相対リンクを踏んだとき（ファイル切替として扱うので
  検索バーごと閉じる）。単一ファイルモードでは遷移先で検索し直す

ヒットは合計 5000 件で打ち切り、カウンタに `+` を付ける（巨大な生成 html で
1 文字ごとに数十万件を作ると、親と共通の UI スレッドごと固まるため）。

キー操作は iframe にフォーカスがあっても効く ── ⌘F / ⌘R / ⌘D / ⌘T / ⌘P / ⌘W、
`]` / `[` / `Tab`、`?`、そしてスクロール素キー
（`j` `k` `d` `u` `Space` `g` `G`。iframe 内の文書が直接スクロールする）。
コメント機能（`c`）は行番号の対応が取れないため html 表示中は使えない。

## `.md` / `.html` 以外のファイル

VSCode 風の**全幅ソースビュー**（行番号ガター＋ファイル名バー付き、構文ハイライト）で
表示される。

レイアウトは統一されていて、レンダリング済み Markdown は 720px 中央寄せ、html は iframe 全面、
ソース／raw／diff は全幅（左寄せ）。
