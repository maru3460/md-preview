# 折りたたみと読み位置

閉じた `<details>` の中身は、レイアウトされていて矩形も持つ（見えていないだけ）。
錨がそれを掴むと、畳まれたブロックの中の行を指してしまう。

<details>
<summary>閉じている（中身は見えない）</summary>

畳まれた中の段落。ここは画面に出ていないので錨になってはいけない。

- 畳まれたリスト 1
- 畳まれたリスト 2

```rust
fn hidden() {}
```

</details>

<details open>
<summary>開いている</summary>

開いた中の段落 1。`<details>` は生 HTML 経由なので終了行を持たず、本文全体を囲む
「1 行のユニット」になる。文書順の最初で錨を決めると、この中はどの行も錨になれない。

開いた中の段落 2。ここを画面上端に置いて測る。

開いた中の段落 3。

開いた中の段落 4。

</details>

生 HTML のブロックは `details` / `summary` の開きタグ以外に行番号が振られないので、
背が高いと「ユニットに覆われていない領域」になる。ここを画面上端に置いて測る。
