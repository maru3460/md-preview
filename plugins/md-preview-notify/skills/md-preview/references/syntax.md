# syntax

md-previewで対応しているマークダウンのシンタックス
基本的にはGithubと同じ

## GitHub と違うもの

### ファイルの中身を埋め込める

ローカルファイルへのリンクを、段落にそれだけで置くと、中身がハイライト付きのコードブロックとして展開される。パスはその md ファイルの場所が基準。

```markdown
[main](./src/main.rs#L10-L20)

[lib](./src/lib.rs)
```

- 文中に混ぜたリンクは展開されず、普通のリンクのまま
- `.md` / `.html` へのリンクは、範囲を付けたときだけ展開される（付けなければペイン内で移動するリンク）
- 100 行を超えると畳まれ、1000 行で打ち切られる。長い引用は埋め込まずにリンクにする

### コードブロックにファイル名を付けられる

言語の後ろに `:パス` を書くと、ブロックの上にファイル名が出る。

````markdown
```rust:src/main.rs
fn main() {}
```
````

### draw.io の図を描ける

```` ```drawio ```` のブロックに `<mxfile>` か `<mxGraphModel>` の XML を書く。
クリックすると全画面になり、拡大と移動ができる。

### 裸の URL は日本語のところで切れる

`詳細はhttps://example.com/aを参照` のように、日本語に続けて書いてもリンクになる。代わりに、パスに日本語が入った URL は途中で切れる。
切りたくないときは `<https://…/ずんだもん>` と山カッコで囲む

### 数式と絵文字ショートコードは描画されない

`$…$`、`$$…$$`、```` ```math ```` は数式にならず、書いたままの文字で出る。`:smile:` のような絵文字ショートコードも変換されない。

- 式は地の文かコードで書く（`O(n log n)`、`x^2 + y^2`）
- 絵文字は文字そのもの（😄）で書く
