# 設定「文書を信頼する」が OFF のとき止まるもの

md は既定で、開いた文書の JavaScript とネットからの読み込みを止める。
設定「文書を信頼する」を ON にした人の窓では、ここに書いたものは全部そのまま動く。
OFF の窓に出す文書を書くときだけ、この表に合わせて書く。

## 止まるもの

- 文書の JavaScript: md のイベント属性（`onclick` など）と `javascript:` のリンク、`.html` の `<script>`。
  JavaScript でデータから組み立てる表やグラフは白紙になる。mermaid の `click` も効かない
- ネットからの読み込み: 外部の画像（バッジを含む）・動画・音声・iframe は、小さな「開く」リンクに置き換わる。
  外部の CSS と Web フォントは黙って効かない
- md の本文の `<script>` 要素と、`<style>` の `@import` / `@font-face` は、設定に関係なく動かない

## 代わりにこう書く

- 画像は手元に置いて相対パスで指す
- 図はインライン SVG か mermaid（手元で描かれる）。CDN から mermaid を読む `.html` は図が出ない
- データから組み立てるものは、組み立てた結果を HTML に書き出す
- コマンドを写させたいときはコードブロックにする（右上に Copy が付く）

## 変わらないもの

手元のファイル（画像・動画・PDF・CSS）、`<details>`・`<kbd>`、本文の `<style>`（本文の中だけに効く）、mermaid と draw.io の図（draw.io の AWS などの拡張図形だけは ON のとき）。
