# keymap

md-previewのキーマップのリファレンス

## よく使いそうなもの

ユーザーのキーボード操作のナビゲーションの場合こちらを案内する

### 読む

- `j` / `k` … 1 行下 / 上。
- `d` / `u` … 半ページ下 / 上。
- `⌘F` … 本文を検索
- `⌘T` … 見出しの目次の表示切り替え

### 届いたものを開く

- `b` … 通知（ベル）を開く。`j` / `k` で選び、`Enter` で開く。`b` か `Esc` で閉じる

### ファイルを行き来する

- `shift + Tab` … 次のタブへ。
- `Tab` … 本文とファイルツリーの間でフォーカスを移す。
- `⌘P` … ファイル名で探して開く。(初期表示ではgit で変更のあるファイルが先頭に並ぶ)

### 表示を切り替える

- `⌘R` … ソース表示
- `⌘D` … git の差分表示

### コメントして AI に渡す

- `c` … コメントモードに入る / 抜ける
- `j` / `k` で対象を選び、`Enter` でコメントを書く。`⌘Enter` で保存。
- `Shift+j` / `Shift+k` … コメント対象の範囲選択
- `n` / `p` … 付けたコメントを順に巡る。`e` で編集、`x` で削除
- `y` … 全部コピー
- `X` … 全部消す

### 困ったら

- `?` … キー操作の一覧を出す
- `Esc` … 開いているものを閉じる

## 全部

### 読み進める

- `j` / `k` … 1 行下 / 上
- `d` / `u` … 半ページ下 / 上
- `Space` / `Shift+Space` … 1 ページ送り / 戻し
- `g` / `G` … 冒頭 / 末尾へ

### 探す・飛ぶ

- `/` … 検索を開く（閉じるのは `Esc` か `⌘F`）
- `⌘F` … 検索を開閉
- `⌘T` … 見出しの目次を開閉
- `⌘P` … ファイル名のあいまい検索。何も打たなければ、git で変更のあるファイルが先頭に並ぶ
- `b` … 通知（ベル）を開閉

### 表示を切り替える

- `⌘D` … git の差分表示
- `⌘R` … ソース表示（md / html のレンダリング前の中身）

### コメント

- `c` … コメントモードに入る / 抜ける。git 差分と 1 万行を超えるソースでは、行に付けられない
- `j` / `k` … コメントする対象を移す。`Shift+j` / `Shift+k` で範囲を広げる
- `Enter` … 選んだ対象にコメントを書く
- `n` / `p` … 付けたコメントを順に巡る。別のファイルのコメントへも飛ぶ
- `e` … コメントを編集
- `x`（または `Delete`）… コメントを削除
- `X` … 全部のファイルのコメントを全部消す。確認なしで、取り消せない
- `y` … 全部コピー

### ファイル・タブを移る

- `]` / `[` … 次 / 前のファイルへ
- `Tab` … 本文とファイルツリーの間でフォーカスを移す
- `⇧Tab` … 次のタブへ。端まで行ったら先頭へ戻る
- `⌘1` … `⌘9` … n 番目のタブへ。`⌘9` は最後のタブ

### ファイルツリー

- `⌘B` … ファイルツリーを開閉
- `⌘[` / `⌘]` … 開いていたフォルダへ戻る / 進む
- `m` … ツリーのカーソル行を Quick Access に留める / 外す
- ツリーにフォーカスがあるとき … `j` / `k` で移動、`g` / `G` で端へ、`Enter` か `l` で開く・展開、`h` で畳む・親へ

### 窓・アプリ

- `⌘,` … 設定をタブで開く
- `⌘A` … 本文を全選択
- `⌃⌘F` … フルスクリーン
- `⌘W` … タブを閉じる。最後の 1 枚なら窓を閉じる
- `⌘⇧W` … 窓を閉じる
- `⌘Q` … 終了
- 右クリック … メニュー
- `?` … キー操作の一覧を開閉
- `Esc` … 検索・メニュー・一覧・コメントを閉じる

### 開いた画面の中で効くキー

- 通知（ベル）… `j` / `k`（`↓` / `↑`）で選ぶ、`Enter` で開く、`b` か `Esc` で閉じる
- ファイル検索（`⌘P`）… `↓` / `↑`、`Tab` / `Shift+Tab`、`⌃n` / `⌃p` で選ぶ、`Enter` で開く
- 検索（`⌘F`）… `Enter` / `↓` で次、`Shift+Enter` / `↑` で前
- コメントの入力欄 … `⌘Enter` で保存、`Esc` で取り消し
