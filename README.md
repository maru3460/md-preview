# md-preview

MarkdownファイルをmacOSのネイティブウィンドウで表示するだけのツール。

```sh
md README.md
```

macOS WebKit（[wry](https://github.com/tauri-apps/wry)）でレンダリングするので軽量・高速。GitHub風スタイル・ダークモード・Mermaid図・draw.io図・シンタックスハイライトに対応。ページ内検索（⌘F）・アウトライン（⌘T）・本文へのコメント（`c`）・選択即コピー・コードブロックのコピーボタン・右クリックメニューも備えています。図のライブラリは図がある時だけ遅延ロードされるので、通常のMarkdownは軽いまま開けます。

`.html` / `.htm` ファイルはページとしてそのままレンダリング表示、それ以外のファイルは行番号付きのソースビュー（シンタックスハイライト）で表示できます。

## インストール

[Rust](https://rustup.rs/) が必要です。

```sh
cargo install --path .
```

`~/.cargo/bin/md` としてインストールされます。`PATH` に含まれていることを確認してください。

## アンインストール

```sh
md uninstall
```

`md` はディスクの 4 か所にものを置きます。`cargo uninstall md-preview` は本体しか消さないので、残りは `md uninstall` でまとめて片付けます。

| 場所                    | 中身                                               |
| ----------------------- | -------------------------------------------------- |
| `~/.config/md-preview/` | テーマ設定・ユーザー CSS・起動用のバンドル（下記） |
| `~/Library/WebKit/md`   | UI の状態（オンボーディング済みフラグなど）        |
| `~/Library/Caches/md`   | WebKit のキャッシュ                                |
| `~/.cargo/bin/md`       | 本体（`cargo uninstall md-preview` に委譲します）  |

本体の削除を cargo に任せるのは、cargo が「どの crate がどの bin を置いたか」を台帳に記録しているためです。バイナリだけ先に消すと台帳とズレて、`cargo install --list` に残り続けます。

`~/Library` 以下の 2 つは、`CFBundleIdentifier` を持たないアプリの既定として**実行ファイル名がそのままディレクトリ名になる**場所です。`md` 専用の名前空間ではないので、`md` という名前の別のプログラムが同じ場所を使っている場合は一覧に出さず、触りません。

> [!NOTE]
> `~/.config/md-preview/app/` には 500 バイト弱の `Info.plist` と本体への symlink を置き、起動時にそこから自分を起動し直しています。macOS に「アプリ」として認識されないと、日本語入力の変換候補ウィンドウが出ないためです。

## 使い方

```sh
md .                       # 作業ディレクトリをルートにして開く
md docs/                   # 指定ディレクトリをルートにして開く
md intro.md                # 作業ディレクトリをルートにして、そのファイルをタブで開く
md ~/other/note.md         # 作業ディレクトリ外のファイル → その親フォルダをルートにして開く
md a.md b.md               # 複数のファイルをタブで開く（先頭が最初に見えるタブ）
cat note.md | md           # 標準入力からMarkdownを読む（パイプ経由）
md --sample                # サンプルMarkdownを標準出力に出力
md --help                  # 使い方を表示（-h も可）
md --version               # バージョンを表示（-V も可）
```

`md` はウィンドウを開いたら即座に終了します（`open` と同じ感覚で、プロンプトがすぐ返ります）。ウィンドウは自分をバックグラウンドへ切り離して残るので、ターミナルを閉じても、呼び出し元が待ち時間の上限でプロセスグループを畳んでも消えません。閉じるときは ⌘W です。

どの開き方でも画面は同じ（サイドバーのツリー＋タブ＋プレビュー）で、変わるのは**ルートがどこになるか**と**起動時にどのタブが開くか**だけです。

- ディレクトリを指定 → そこがルート。タブは開きません
- 作業ディレクトリ内のファイルを指定 → 作業ディレクトリがルート。そのファイルがタブで開きます
- 作業ディレクトリ外のファイルを指定 → 指定したファイルたちの共通の親がルート（1 つならその親フォルダ）
- パイプ（`cat note.md | md`）→ 作業ディレクトリがルート。渡された内容は一時ファイルに書き出され、「ルートの外のファイル」としてタブで開きます（ツリーには出ませんが、Raw 表示・git 差分・コメントは他のファイルと同じように使えます）

機能を一通り試したいときは：

```sh
md --sample > sample.md && md sample.md
```

## ファイルツリー

サイドバーにディレクトリツリーが表示されます。ファイルをクリックするとプレビューペインに表示されます。Markdownファイル内の相対リンクもプレビューペイン内で遷移します。サイドバーの幅はドラッグでリサイズできます。

Markdownファイルを含まないディレクトリは自動的にツリーから除外されます。

### 相対パスの基準

画像（`![](fig.png)`）もリンク（`[b](./b.md)`）も、**開いているフォルダではなく、そのMarkdownファイルがある場所**を基準に解決します。`docs/a.md` の `fig.png` は `docs/fig.png` を指します。

開いているフォルダの外を指すパス（`../assets/fig.png` や `[外](../../other/x.md)`）も解決します。フォルダの外のファイルを開いた場合、サイドバーのツリーには行がありませんが、タブには並び、編集すれば自動リロードも効きます。

## タブ

開いたファイルは本文の上のタブバーに積まれます。複数のファイルを開いたまま行き来できます。

- ファイルを開くたびに新しいタブができます（ツリー・`[` `]`・⌘P・本文のリンク、どの経路でも同じです）。
- タブごとに**読み位置**と**表示モード（Raw / 差分）**を覚えているので、戻ってきたときは離れたときの状態が復元されます。
- **⌘W** でタブを閉じます。最後の 1 枚を閉じるとウィンドウが閉じます（ウィンドウを直接閉じるのは **⌘⇧W**）。
- **⇧Tab** で次のタブへ移動します（端まで行ったら先頭へ折り返します）。**⌘1** … **⌘9** で n 番目のタブへ直接飛べます（⌘9 は最後のタブ）。
- タブのクリックで切り替え、中クリックか `×` で閉じる。右クリックで「閉じる / 他のタブを閉じる / パスをコピー」などが出ます。
- 同じファイル名のタブが並んだときだけ、親ディレクトリ名が添えられます。

## 検索・アウトライン

- **⌘F** … ページ内検索バーを開閉する（⌘R / ⌘D / ⌘T と同じトグル。もう一度押せば閉じます。入力欄・本文・iframe のどこにフォーカスがあっても閉じられ、閉じても入力した語は残るので再度 ⌘F で続けられます）。`Enter` / `Shift+Enter`（または `↑` `↓`）で前後のヒットへ移動、`Aa` ボタンで大文字小文字の区別を切り替え、`Esc` でも閉じる。選択テキストがあれば初期クエリに入ります。HTML 表示中は iframe の中身も検索できます（制限は後述）。ヒットが多いときは 5000 件で打ち切り、カウンタに `+` が付きます。
- **⌘T** … 見出しのアウトラインパネルを開閉する。項目クリックでその見出しへスクロールし、スクロールに追従して現在位置がハイライトされます。
- **⌘P** … ファイル検索。後述。

## ファイル検索（⌘P）

**⌘P** を押すと、ルート以下の全ファイルからファイル名で**あいまい検索**して開けます。深い階層のファイルもツリーを掘らずに一発で開けます。

- `keymap` はもちろん `km` のような飛ばし打ちでも当たります（部分列マッチ）。`docs/comment` のように `/` を含めればパスでも絞れます。
- `↑` `↓`（`⌃n` / `⌃p`・`Tab`）で移動、`Enter` で開く、`Esc` で閉じる。行のクリックでも開けます。
- 一覧からは `.git` / `node_modules` / `target` / `dist` / `build` などの依存物・生成物ディレクトリを除外しています（`.github` のような設定系の隠しディレクトリは対象に含まれます）。サイドバーのツリーは従来どおり全部表示するので、除外されたファイルもツリーからは開けます。
- 探索は**幅優先**（浅い階層から順）です。ファイル 20,000件 / ディレクトリ 50,000件 / 深さ 16 階層のいずれかの上限に当たると打ち切り、**「どの上限で打ち切ったか」をパレット上部に警告表示します**。浅い階層から埋めるので、上限に当たっても浅い階層のファイルは必ず一覧に入ります。

## コメント（`c`）

`c` キーで**コメントモード**に入ると、レンダリング済み本文の各ユニット（見出し・段落・リスト項目・表・引用・コードブロック・`<details>` の折りたたみ・フロントマター）にその場でコメントを付けられます。

- ホバーで左に `+` が出て、クリックでそのユニットを対象にコメント入力ポップオーバーが開きます。**ドラッグで複数行をまとめて 1 コメント**にできます（レンジ）。
- **マウス無しでも操作できます**。モード中は `j`/`k`（`↑`/`↓`）でユニット間を移動、`Shift+j`/`Shift+k` でレンジ選択、`Enter` でコメント入力を開きます。
- ポップオーバーは `⌘+Enter` で保存 / `Esc` で取消。保存すると対象の左に色帯と 💬 バッジが付き、右下パネルに 1 件追加されます。バッジのクリックで編集、コメント済みユニットにホバーすると内容がプレビュー表示されます。
- 付けたあとも **キーボードだけで見直せます**。`n`/`p` で次 / 前のコメントへジャンプ（別ファイルのコメントなら自動で開く）、`e` で編集、`x`（または `Delete`）で削除、`X` で全消去、`y` で全部コピー。
- 右下パネルの「**全部コピー**」で、次の形式に畳んでクリップボードへ入ります。そのまま Claude Code などに貼れば、ファイルと行を指したレビュー指摘になります。

```text
- docs/plan.md:15
> 認証は JWT を使う。アクセストークンは短命にして…

リフレッシュトークンの扱いは？
```

**raw 表示（⌘R）と非 md ファイルのソースビューでも付けられます**。こちらは 1 行が 1 ユニットで、クリック / ドラッグで行や範囲を指定します。コメントは付けたときの表示を覚えていて、一覧では raw 由来に `raw` の印が付き、`n` / `p` の巡回はその表示へ切り替えてから着地します。行番号はどちらもソースの行なので、プレビューで付けたコメントと raw で付けたコメントは同じ `file:line` の並びに混ざります。ただし**本文への印（色帯・💬 バッジ・埋め込み）は付けた表示にだけ出ます**——raw の行コメントをプレビュー側のブロック全体（段落・コード・Mermaid 図）へ落とすと、錨として粗すぎるためです。もう一方の表示で付けたコメントは一覧から辿れます。

別ファイルへ移ってもパネルに蓄積され続けます。コメントはセッション内のメモリのみで、ファイルには保存されません。`.html` の iframe 表示・git 差分（⌘D）・10,000 行を超えるソースには行コメントを付けられません（モードには入れて、`n` / `p` の巡回・`y` の全部コピー・`X` の全消去は使えます。`j` / `k` は本文スクロールのまま残り、サイドバーの先頭に付けられない旨が出ます）。

## 選択即コピー

マウスで範囲を選択すると、その場でクリップボードに入ります（⌘C は不要）。iTerm2 の "Copy to pasteboard on selection"、Ghostty の `copy-on-select`、[herdr](https://herdr.dev/) の `ui.copy_on_select` と同じ挙動です。ドラッグ選択のほか、ダブルクリックの単語選択・トリプルクリックの段落選択でも入ります。選択はそのまま残ります。

入ったことは、マウスを離した位置に出る小さなチェックで分かります。読んでいる最中に何度も出るものなので、文字は出さず 0.6 秒で消えます（失敗したときだけ文字で知らせます）。

クリップボードに入る文字は、コードの記法を Markdown のソースへ戻したものです。インラインコードはバッククォートで包まれ、コードブロックは ` ```rust ` のようなフェンス付き（`` ```言語:ファイル名 `` で書いたブロックはその情報のまま）で入ります。ブロックを跨いでなぞっても、Copy ボタンやファイル名バーの文字は混ざりません。戻すのはコードの記法だけで、太字やリンク・表は見えている文字のまま入ります（文章をそのまま貼りたいことの方が多いため）。raw 表示（⌘R）・git 差分（⌘D）・`.html` の iframe は元から原文なので触りません。

`.html` の iframe 表示の中でも効きます。入力欄（コメント本文や検索バー）の中の選択では走りません。コメントモード中は、本文のドラッグが行の範囲選択に割り当たっているため、ページ全体で走りません（`.html` の iframe の中だけは効いたままです）。

キーボードでの選択（⌘A や Shift+矢印）はクリップボードに入りません。マウス操作だけが対象です。

## 右クリックメニュー

プレビュー領域やサイドバーのツリー項目を右クリックすると、コンテキストメニューが開きます。

- 選択テキストのコピー
- 相対パス / 絶対パスのコピー
- Finderで表示
- デフォルトアプリで開く
- ファイル検索
- 再読み込み

タブを右クリックした場合はそのタブ（「閉じる」「他のタブを閉じる」が加わります）、サイドバーのツリー項目を右クリックした場合はその項目が、それ以外ではプレビュー中のファイルが操作対象になります。

## キーボードショートカット

- **⌘F** … ページ内検索の開閉（トグル）
- **⌘P** … ファイル検索（ファイル名のあいまい検索で開く）
- **⌘T** … アウトライン表示
- **⌘R** … Raw（生ソース）表示の切り替え（`.md` / `.html` で有効。右下のトグルでも可）
- **⌘D** … Git 差分表示の切り替え（右下のトグルでも可）
- **c** … コメントモードの切り替え（モード中は `j`/`k` 移動・`Enter` 付与・`n`/`p` 巡回・`e` 編集・`x` 削除・`X` 全消去・`y` 全部コピー。マウスでも可）
- **⌘A** … 本文（`.markdown-body`）だけを全選択（サイドバー等は巻き込みません）
- **⌃⌘F** … フルスクリーンの切り替え（緑ボタンと同じ。macOS 標準のキー）
- **⌘W** … タブを閉じる（最後の 1 枚ならウィンドウを閉じる）
- **⌘⇧W** … ウィンドウを閉じる
- **⇧Tab** … 次のタブへ（端まで行ったら先頭へ折り返す）
- **⌘1** … **⌘9** … n 番目のタブへ（⌘9 は最後のタブ）
- 標準の編集メニュー（Undo / Redo / Cut / Copy / Paste / Select All）も利用できます。

## テーマ

`md theme` コマンドで配色を丸ごと切り替えられます。

```sh
md theme                   # テーマ一覧を表示（使用中のテーマに ● 印、ターミナルでは色見本付き）
md theme dracula           # テーマを切り替える（~/.config/md-preview/active-theme に保存される）
```

組み込みテーマ：

| 区分 | テーマ |
| --- | --- |
| light（固定） | `minimal` `editorial` `ink` `paper` `mono` `solarized-light` |
| dark（固定） | `nord` `dracula` `gruvbox` `rose-pine` `terminal` `blueprint` |
| auto（OS設定に追従） | `default` |

light / dark 固定のテーマはシンタックスハイライトの配色もそれに合わせて固定され、OSのダークモード設定の影響を受けません。

### ユーザーテーマ

`~/.config/md-preview/themes/<名前>.css` にCSSファイルを置くと、`md theme <名前>` で選べる独自テーマになります。組み込みと同じ名前を使うと、そちらが優先されます（`md theme` の一覧に `（ユーザー定義で上書き）` と表示されます）。ユーザーテーマはOS設定に追従（auto）します。テンプレートには `default` テーマのCSSを写すのが手軽です。

## カスタムCSS

`~/.config/md-preview/style.css` にCSSファイルを置くと、デフォルトのスタイルを上書き・拡張できます。テーマよりさらに後ろに適用されるので、選んでいるテーマはそのままに細部だけ微調整したいときに使えます。

```css
/* 例: コンテンツ幅を広げる */
.markdown-body {
    max-width: 1000px;
}
```

## 対応するMarkdown機能

GFM・コードブロックのシンタックスハイライト・[Mermaid](https://mermaid.js.org/) 図・[draw.io](https://www.drawio.com/) 図・GitHub風アラート（`> [!NOTE]` 等）・ファイル名付きコードブロック（` ```rust:src/main.rs `）・YAML front matter・ダークモード（システム設定に追従）など。コードブロックにはホバーで現れるコピーボタンが付きます。

draw.io 図は ` ```drawio ` コードブロックに draw.io の XML（`<mxGraphModel>` または `<mxfile>`）を貼ると描画されます。図をクリックすると全画面表示になり、ズーム・パンできます。Mermaid / draw.io のライブラリは図が含まれるときだけ遅延ロードされます。

### ファイルリンクのコード埋め込み

ローカルファイルへのリンクを**段落に単独で**置くと、そのファイルの中身がコードブロックとして展開されます（GitHub のパーマリンク埋め込みのローカル版）。パスはその Markdown ファイルがある場所を基準に解決します。

```markdown
[main](./src/main.rs#L10-L20)   ← 10〜20行目を展開
[open](./src/main.rs#L5)        ← 5行目だけ展開
[lib](./src/lib.rs)             ← ファイル全体を展開
```

ヘッダの左にパス、右に行範囲が出ます。文中に置いたリンク・外部URL・見出しアンカー・存在しないパス・バイナリ・行範囲がファイル外の場合は展開されず、普通のリンクとして残ります。読むのはローカルファイルだけで、ネットワークアクセスは行いません。

100 行を超える埋め込みは畳まれて先頭 40 行だけ表示され、下端の「すべて表示（N 行）」バーで開閉できます。1000 行がハード上限で、範囲を明示していてもそこで打ち切り、ヘッダに `L1-L1000 / 全 1500 行` のように総行数を表示します。

`.md` / `.html` への**範囲なし**のリンク（`[次へ](./other.md)`）はプレビューペイン内で遷移するナビゲーションなので、埋め込みには変換しません。これらを展開したいときは `./other.md#L2-L8` のように行範囲を付けてください。

実際の出力サンプルは `md --sample > sample.md && md sample.md` で確認できます。

## HTMLファイル・ソース表示

`.html` / `.htm` ファイルを開くと、`<iframe>` で**そのままレンダリング表示**されます（CSS も JavaScript も効く、ミニブラウザのような表示）。右下の **Raw** トグル（**⌘R**）で生ソース表示に切り替えられます。手元のローカルファイルを忠実に見る用途に振り切っているため sandbox は付けていません（後述のセキュリティを参照）。

`.md` / `.html` 以外のテキストファイルは、行番号付きの**全幅ソースビュー**（ファイル名バー＋シンタックスハイライト）で表示されます。レンダリング済みMarkdownは中央寄せ、HTMLはウィンドウいっぱいのミニブラウザ、ソース／Raw／差分は全幅、という統一レイアウトです。

> [!NOTE]
> ページ内検索（⌘F）は HTML の中身にも効きます。ヒットの色付けには CSS Custom Highlight API を使うので、表示中の HTML の本文 DOM は書き換わりません（ページ自身の JavaScript とぶつからない）。ただし cross-origin へ遷移した iframe、shadow DOM の中、CSS Custom Highlight API 非対応の WebKit（Safari 17.2 未満）では検索できません。素キーの `/` は iframe にフォーカスがあるときは効きません（`/` を自前の検索に使う HTML と衝突するため。⌘F を使ってください）。アウトライン（⌘T）も HTML の中身には効きません。⌘R などアプリのショートカットは iframe にフォーカスがあっても動作します。

## 自動リロード

表示中のファイル（Markdown / HTML）を編集して保存すると、自動でプレビューが更新されます。スクロール位置は維持されます。

## セキュリティ

`md` は**自分と AI が書いたファイルを見る**ためのツールで、開いたファイルを隔離しません。`.md` の本文も `.html` ファイルも、書かれたとおりに描画・実行されます。

- `.md` 本文の HTML はサニタイズしていません。埋め込まれた `<script>` や `on*` 属性はそのまま実行され、外部の CSS・Web フォント・`<iframe>` 埋め込み（YouTube 等）も通ります。
- `.html` / `.htm` は「手元のローカルファイルを忠実に見る」用途のため、sandbox なしの同一オリジン iframe で描画します。中の JavaScript はそのまま動き、ローカルのファイルを読んで外部へ送信することもできます（フォルダの外を指す画像・リンクを解決する都合で、読める範囲は開いているフォルダ配下に限りません）。

つまり **`md` で開くファイルは、ブラウザで開く HTML と同じ目線で選んでください。出所の分からない `.md` / `.html` を開くのは避けてください。**

残しているガードは、事故を減らすための最低限だけです。

- 右クリックメニューからのパス操作（絶対パスのコピー・Finderで表示・デフォルトアプリで開く）は Rust 側でパスを検証し、実行系の拡張子（`.app` / `.command` / `.jar` 等）は弾きます。
- アプリ本体への IPC（クリップボード書き込み・パス操作・ファイル監視）は送信元を見て、トップフレーム以外からのものは落とします。ただしこれは悪意あるファイルへの対策にはなりません（iframe は同一オリジンなので、アプリのシェルを読み込んだフレームを自前で作れば、その経路の IPC はトップと区別が付きません）。

## Claude Code プラグイン

このリポジトリは [Claude Code](https://claude.com/claude-code) のプラグインとしても配布しています。`md` コマンドの使い方をまとめたスキルが同梱されており、Claude Code から Markdown を人に見せたいときに `md` を使えるようになります。

インストール（Claude Code 内で実行）：

```
/plugin marketplace add maru3460/md-preview
/plugin install md-preview@md-preview
```

### プラグインの更新

`marketplace add` で入れたプラグインは、リポジトリ側でバージョンが上がっても自動では更新されません。最新版に更新するには、マーケットプレイスのメタデータを取り直してから再インストールします（Claude Code 内で実行）：

```
/plugin marketplace update md-preview
/plugin install md-preview@md-preview
```

反映されたかは `/plugin list`、または `/plugin` → **Installed** タブ（**Last updated** 日付）で確認できます。

### 自動更新を有効にする

カスタムマーケットプレイス（GitHub リポジトリ）はデフォルトで自動更新が無効です。有効にすると起動時に自動で最新版へ更新されます。

1. `/plugin` を開く
2. **Marketplaces** タブ → `md-preview` を選択
3. **Enable auto-update** を選ぶ

以降はバージョンを上げて push するだけで、次回起動時に反映されます。

### プラグインのアンインストール

```
/plugin uninstall md-preview@md-preview
```

マーケットプレイスの登録ごと削除する場合は：

```
/plugin marketplace remove md-preview
```

> [!NOTE]
> プラグインに含まれるのはスキル（`md` の使い方チートシート）のみです。`md` コマンド本体は上記「インストール」の `cargo install --path .` で別途セットアップしてください。プラグインを消しても `md` コマンドは残るので、本体も消すには `md uninstall`（上記「[アンインストール](#アンインストール)」）を実行してください。
